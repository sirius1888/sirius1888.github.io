# UI kit

Общие компоненты импортируются из `src/ui-kit`. Они получают текст, состояние и действия через props. Внутри нет данных портфолио, переводов, рекламных правил или доступа к хранилищу. Стили подключаются один раз через `ui-kit.css`; цвета и размеры берутся из `tokens.css`.

## Компоненты

| Компонент                            | Назначение и API                                                                                                                       | Поведение                                                                                                                                                                                                                                       |
| ------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Button](./Button.tsx)               | Базовая кнопка; стандартные props и `ref` HTML-кнопки.                                                                                 | По умолчанию `type="button"`. Отправка формы требует `type="submit"`. Сохраняет `disabled`, клавиатурное управление и обработчики. Внешний вид задаёт `className`.                                                                              |
| [IconButton](./Button.tsx)           | Действие с иконкой: обязательные `label: string`, `icon: ReactNode`; остальные props — как у `Button`.                                 | `label` становится доступным именем. Иконка не заменяет текстовое описание действия.                                                                                                                                                            |
| [ToggleButton](./Button.tsx)         | Двоичное действие: `pressed`, `onPressedChange(next)`, `children`, нативные props кнопки.                                              | Управляемое состояние и `aria-pressed`. Клик сообщает следующее значение; сам компонент состояние не меняет.                                                                                                                                    |
| [ToggleField](./ToggleField.tsx)     | Переключатель с пояснением: `icon`, `title`, `description`, props `ToggleButton`.                                                      | Композиция `ToggleButton`; индикатор декоративный. Используется для аналитики, экспериментов и consent.                                                                                                                                         |
| [Link](./Link.tsx)                   | Навигация и скачивание: нативные props и `ref` ссылки.                                                                                 | Сохраняет `href`, якоря, `mailto:` и `download`. Для `target="_blank"` добавляет `noopener noreferrer`, сохраняя остальные значения `rel`.                                                                                                      |
| [ChoiceGroup](./ChoiceGroup.tsx)     | Выбор значения: `label`, `value`, `options`, `onValueChange`. Опция содержит `value`, `label` и может содержать дополнительные данные. | Рендерит группу обычных кнопок с `aria-pressed`. `renderOption(option, selected, index)` задаёт содержимое. Не добавляет поведение tabs/radio. Повторный клик передаёт текущее значение владельцу; это позволяет включать и выключать сценарий. |
| [SectionMeta](./SectionMeta.tsx)     | Строка раздела: `index`, `label`, необязательный `aside`, `className`.                                                                 | Номер и название плюс слот для дат или платформ. По умолчанию использует `chapter-overline`.                                                                                                                                                    |
| [SplitHeading](./SplitHeading.tsx)   | Заголовок в две колонки: `titleId`, `title`, `leading`, `subtitle`, `detail`.                                                          | Выводит `h2` с идентификатором и дополнительную информацию. Изображения и текст передаются извне.                                                                                                                                               |
| [ProductLabel](./ProductLabel.tsx)   | Подпись над устройством: `image`, `title`, `detail`.                                                                                   | Логотип декоративный: название уже присутствует рядом текстом.                                                                                                                                                                                  |
| [DeviceFrame](./DeviceFrame.tsx)     | Рамка iPhone: обязательные `label`, `children`, необязательный `className`.                                                            | Содержимое приложения передаётся через `children`. Рамка не знает о звонках или рекламе. Статус-бар и физические детали декоративные.                                                                                                           |
| [ListRow](./ListRow.tsx)             | Строка с иконкой и пояснением: `leading`, `title`, `description`, необязательные `trailing`, `className`.                              | Только разметка. Стрелка или другое содержимое в `trailing` сами по себе не создают действие. Используется в библиотеке и списке конференций.                                                                                                   |
| [MessageBubble](./MessageBubble.tsx) | Сообщение: `children`, необязательные `author`, `outgoing`, `receipt`.                                                                 | Разделяет отображение входящих и исходящих сообщений. Отправка, история и статусы доставки остаются у владельца.                                                                                                                                |
| [DialogSurface](./DialogSurface.tsx) | Встроенный диалог: `label`, `onDismiss`, `initialFocusRef`, `children` и props `section`.                                              | При открытии фокусирует заданную кнопку, обрабатывает Escape и при закрытии возвращает фокус. Это немодальный диалог внутри демо: без `aria-modal`, портала и блокировки остальной страницы.                                                    |

`ChoiceGroup` дополнительно принимает `id`, `className`, `controls`. Последний параметр связывает кнопки с управляемой областью через `aria-controls`. Если `value` не соответствует ни одной опции, все кнопки отображаются ненажатыми.

## Примеры

```tsx
<IconButton
  className="icon-button"
  label="Close preview"
  icon={<X size={18} />}
  onClick={closePreview}
/>

<ToggleField
  pressed={analyticsEnabled}
  onPressedChange={setAnalyticsEnabled}
  icon={<ChartNoAxesCombined size={22} />}
  title="Analytics"
  description="Demo events"
/>

<ChoiceGroup
  label="Advertising SDK"
  value={sdk}
  options={sdkOptions}
  onValueChange={setSdk}
  renderOption={(option, selected) => (
    <>{option.label}{selected && <Check size={13} />}</>
  )}
/>
```

Все значения состояния и обработчики в примерах принадлежат вызывающему компоненту. Нативные props не подменяются собственными `as`, `asChild` или универсальным объектом конфигурации.

## Вспомогательный хук

[useEscapeKey](./useEscapeKey.ts) принимает обработчик необработанного Escape на уровне документа. Отписывается при размонтировании и смене обработчика. `DialogSurface` останавливает всплытие Escape, поэтому закрытие рекламы не сбрасывает другие демо.

## Расширение

- Сначала используется композиция через `children`, слоты и callbacks.
- Новый компонент добавляется при общей ответственности или повторяющейся разметке. Данные работодателей, тексты и сценарии остаются в `features`.
- Стили примитивов находятся в `ui-kit.css`. Раскладка разделов и специфические поверхности приложений — в стилях страницы.
- `ui-kit.test.tsx` проверяет нативные контракты, управляемость и фокус. `src/architecture.test.ts` запрещает зависимости UI kit от данных и бизнес-модулей.

Полная карта компонентов и применение SOLID — в [документации архитектуры](../../docs/COMPONENTS.md).
